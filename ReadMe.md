# 💫 About Me:
Hi, I'm Om<br><br>Backend and cloud engineer who likes working close to the metal. I completed my MCA at the Department of Computer Science, Pune University, and work on serverless microservices on AWS. In college I built systems projects in C, Bash and PostgreSQL.<br><br> What I do<br>- Build backend services with **Java and Spring Boot** on **AWS** (Lambda, DynamoDB, API Gateway, Cognito, CDK)<br>- Work on workflow orchestration, access control and data migration for a background verification platform<br>- Explore how far databases, web servers and operating systems can be pushed without extra layers in between<br><br># Projects<br>- EduLinkBridge: a Telegram bot framework that runs entirely inside PostgreSQL (PL/pgSQL and Bash), with no external web backend. It uses stored functions, triggers and message sync across virtual groups.<br>- English–Devanagari Transliteration Engine: real-time Roman ↔ Devanagari conversion for Hindi and Marathi, written in pure Bash, Awk and Sed and served through FastCGI on Apache.<br>- Memory Block-Based Search: a hierarchical search structure in C for data held across a small RAM and slower block storage, built to cut block fetches.<br>- Virtual Filesystem: an ext2-inspired filesystem in C with FUSE mounting and an HTTP interface.<br><br><br># Get in touch<br>- 📍 Pune, India<br>- 💼 [LinkedIn](https://linkedin.com/in/om-dahake)<br>- 📧 omdahake14@gmail.com
